# CipherVault - Custom Templates Edition

A zero-knowledge local password manager built with React, Vite, Material UI (MUI v5), and the browser Web Crypto API.

## Implemented Features
1. **Custom Item Templates & Specialized Fields**: Support for specialized structured templates including **Crypto Wallets (BIP39 Seed Phrases & Derivation Paths)**, **Server SSH Key Configs (PEM Private Keys & Passphrases)**, and **Wi-Fi Router Credentials**.
2. **Google Auth QR Code & Vault Backup JSON Imports**: Dedicated import buttons for backup JSONs and external authenticator migration payloads.
3. **Standalone Quick 2FA View & Multi-User Profiles**: Access rolling 2FA codes without full vault unlocks.
